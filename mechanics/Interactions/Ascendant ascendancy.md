The Ascendant is the Scion's main ascendancy (tree start node 35754, behind the Scion class start 58833): a player picks branches from the six other base classes instead of one ascendancy tree of their own. 50 nodes: the start, 6 attribute nodes, 12 Passive Point nodes, 6 multiple-choice parents (one per base class, no stats), 6 Path of the X nodes, and 18 options (three per base class). PoB types the 18 options as Normal, not Notable, and also carries the hidden Unleashed Potential (19355), which is not on this tree at all and comes only from Forbidden Flame and Flesh. The options are reduced composites of the source ascendancy's lines, not copies of one notable (see the mirror check below). No sample build is an Ascendant (a scan of every build by ascendClassName found none): nothing here was measured in a headless run, so there is no measured table and no PoB delta; every figure is tree text, wiki quote or PoB source. Mechanics that have their own note are linked, not repeated: the option's source ascendancy where a note exists (table below), [[Forbidden Flame and Flesh]] (Unleashed Potential).

Pipeline: the options act wherever their source lines act: [[Damage calculation#More and less]] - Berserker's 15% more, Trickster's 2% more per mastery type, Saboteur's averaged area-hit more; [[Damage calculation#Critical strike]] - Assassin's base crit; [[Damage calculation#Resistance, exposure and penetration]] - Inquisitor and Warden penetration, Elementalist's extra exposure; [[Receiving damage#Immunity and avoidance]] - Juggernaut, Berserker and Occultist stun immunity, Chieftain's ignite immunity; [[Receiving damage#Recovery]] - Guardian's burst regeneration; the Path nodes act on the passive tree graph, not in the damage pipeline.

Graph and point cost (tree.lua `in`/`out` lists and a live in-memory path test; cap 8 ascendancy points, Modules/Build.lua:902). Each of the six branches has the same shape: attribute node, Passive Point, the multiple-choice parent, then either one of 3 options (leaves) or a second Passive Point and the Path of the X node, which leads to two ordinary tree nodes in that class's region.

Point cost: an option branch (attribute, Passive Point, parent, option) costs 3 points because PoB does not count multiple-choice options (Classes/PassiveSpec.lua:846-865, line 851: `ascUsed` skips `isMultipleChoiceOption`); a Path branch (attribute, Passive Point, parent, second Passive Point, Path node) costs 5. Live test in memory: Berserker allocated gave ascUsed 3, Path of the Marauder added gave ascUsed 5. 8 points = an option branch (3) plus a Path branch (5), or two option branches (6) with 2 spare. PoB only warns above 8 (Modules/Build.lua:926 'You have too many ascendancy points allocated'; no cap in `AllocNode`, Classes/PassiveSpec.lua:781-826); the wiki says up to two Ascendancy class passives plus one class's path, and one option per base class (rev 1674327). PoB enforces only the one-option-per-parent rule: allocating an option deallocates the other options of the same parent (Classes/PassiveSpec.lua:801-808; live: Juggernaut on switched Berserker off), so up to six options can coexist by PoB's rules (read from code; three branches were not allocated). Passive-point refund: each Passive Point node carries ExtraPoints 1 and each Path node ExtraPoints 2 (ModParser.lua:2507), raising the passive-point maximum (Modules/Build.lua:901-902): an option branch refunds 1, a Path branch 1+1+2 = 4 (my arithmetic from the live ExtraPoints values, not an allocation test).

Path of the X nodes are graph-only. Their first line "Can Allocate Passives from the X's starting point" parses to an empty mod on purpose (Modules/ModParser.lua:2508); the effect is that the path search may leave the ascendancy at distance zero into the two outward nodes (Classes/PassiveSpec.lua:1655-1667, comment 'Ascendant paths may leave at distance zero'), the Ascendant start counts as a valid root (870-895) and a node is connected to the start when it links to a ClassStart or an AscendClassStart (1475). Live test in memory: node 31628 had path distance 15 before Path of the Marauder (24755) and 1 after; the Marauder's own start node was not needed. Unverified: whether the outward nodes set the ConnectedTo<Class>Start conditions that some jewels read (Classes/PassiveSpec.lua:1722-1727).

Forbidden Flame and Flesh: PoB's class list skips Scion for Notable ascendancy nodes but adds every Ascendant option and Unleashed Potential through the Normal branch (Classes/PassiveTree.lua:586-608), so `data.uniques.generated` holds 19 Scion variants per jewel (Data/Uniques/Special/Generated.lua:549-592), including 'Variant: (Scion) Unleashed Potential', each with 'Requires Class Scion' and 'Allocates <name> if you have the matching modifier on Forbidden Flesh/Flame' (live check, PoB 2.67.2). The granted node goes into the build's allocated set but not into the ascendancy count (Modules/CalcSetup.lua:1401-1415), so it costs no ascendancy point. Wiki Forbidden Flame rev 1675689: the Scion version allocates one of the Ascendant class notables and can be used even if it is the same class as a notable already allocated.

Mirror check (numbers ignored): 55 of the 78 option lines have a text match in a notable of the source ascendancy, 61 matched line pairs, and every pair has the same live status (applied, dropped, unparsed) as its source line; 23 option lines have no match (Ascendant-only wording). So an option inherits each dropped or unparsed line of its source, and its numbers are lower: Berserker 15% more against Aspect of Carnage's 40% more; Guardian's Unwavering Faith 25% against 50% reservation efficiency; Trickster's 6% against 15% suppressed spell damage prevented; Elementalist's 10% shock minimum against 25%; Champion's 10% taunted damage against 15%.

Grades (live parse): the 18 options plus Unleashed Potential are 19 stat-carrying notables: 9 full, 10 partial, 0 none. Lines: 83 in total, 71 applied, 5 dropped (parsed with leftover text and discarded by PoB, Classes/PassiveTree.lua:860-862), 7 unparsed. Wiki class page rev 1674327 lists the same 18 options and 6 Path nodes with the same lines as tree.lua (the only mismatch is 'Grants 2 Passive Skill Points', which the wiki table does not print); it is not stale. 3.28.0 changed the Assassin option to 'Damage cannot be Reflected', 3.25.0 replaced Raider with Warden.
