# Glossary: the agreed vocabulary

The owner and Claude use these terms with exactly these meanings throughout the project (owner, 2026-10-26). If the
owner uses a term that isn't here, or uses one differently, Claude says it doesn't understand and points out the drift.
New terms are added only when both agree.

| Term | Meaning | Example |
|---|---|---|
| comfort | How smooth a build is to play: you never stand still, and you have permanent phasing (you walk through enemies). | Cyclone gives comfort: always moving, never blocked by mobs. |
| scaling vector | One category of modifiers that scales a number: base or flat damage, increased, more, crit chance, crit multi, penetration and resistance, enemy damage taken, speed, projectiles; defence vectors in the same way. | "You have 1000% increased but only 10% more." |
| increased | Additive: all increased (and reduced) modifiers go into one pool that multiplies the base once. | +20% increased on top of 1000% increased is worth about +2%. |
| more | Multiplicative: each more (or less) modifier multiplies on its own. | 20% more is always worth +20%. |
| build-enabling | An item, gem or node without which the build doesn't work or loses most of its damage. Test: remove it and see what breaks. | Nimis for return-projectile shotgunning. |
